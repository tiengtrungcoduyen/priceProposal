# **App Name**: QuoteCraft

## Core Features:

- Material Input Form: Display a form with a list of materials and quantity fields for each.
- Price Input: Allow the bidder to input the price for each material.
- Total Price Calculation: Automatically calculate the total price based on the entered prices and quantities.
- Bidder Information: A field for the bidder to enter their name.
- Data Submission: Submit the form data to the specified URL upon submission.

## Style Guidelines:

- Primary color: Deep sky blue (#42A5F5) for a trustworthy and professional feel.
- Background color: Light gray (#FAFAFA) to ensure readability and a clean interface.
- Accent color: Orange (#FFB74D) to highlight important actions such as submitting the quote.
- Font: 'Inter', a grotesque-style sans-serif, suitable for body text, to give the app a modern and objective feel.
- Use Lucide React icons for a consistent and clean UI.
- Utilize Tailwind CSS for responsive and utility-first styling.
- Subtle transitions and animations on form elements and button interactions.
